# 📄 Chat With PDF — AI Powered App

Upload any PDF and ask questions in Hindi or English!
AI will answer from the PDF content.

## 🚀 Features
- Upload any PDF file
- Ask questions in Hindi & English
- Powered by Google Gemini AI
- Chat history maintained
- Beautiful UI

## 🛠️ Tech Stack
- Python
- Streamlit
- Google Gemini AI
- PyPDF2

## ▶️ How to Run
1. Clone the repo
2. Install libraries:  pip install -r requirements.txt
3. Add your Gemini API key in .env file
4. Run: streamlit run app.py
